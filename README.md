# Theologia Library · 개인 신학 서재

흩어진 PDF·EPUB 신학 문헌을 작품(책) 단위로 묶어 관리하고, 앱 안에서 바로 읽는 개인 서재입니다.
Windows와 Mac에서 쓸 수 있습니다. 제작: 좋은군사

## 주요 기능
- 폴더를 연결하면 PDF·EPUB을 찾아 책 단위로 정리하고, 성경 66권·신학 분류를 자동으로 붙입니다.
- 앱 안 리더: 읽은 위치 자동 기록, 이어 읽기, 목차·책갈피, 책 안 검색(PDF·EPUB).
- 카카오(다음) 책 검색·국립중앙도서관으로 표지·저자·출판사·ISBN 자동 채우기(각자 API 키를 설정 창에 입력).
- 모든 서재 기록은 내 컴퓨터에만 저장됩니다.

## 시작하기
1. 설치 파일(`Theologia-Library-Setup.exe`, 릴리스 페이지)로 설치하거나, 압축형을 풀어 실행합니다. (서명이 없어 윈도우가 처음에 경고를 띄울 수 있습니다. "추가 정보 → 실행")
2. 처음 화면에서 **폴더 연결**을 눌러 책 폴더를 고릅니다.
3. 자동 분류가 돌면 왼쪽 **분류 확인 필요**에서 틀린 것을 고칩니다. 여러 권을 선택하면 **분류 바꾸기**로 한꺼번에 바꿀 수 있습니다.
4. 설정 창에 카카오 키를 넣으면 표지·저자 정보를 채웁니다. 키가 없어도 서재는 쓸 수 있습니다.

## 백업과 옮기기
- 설정 창의 **백업 파일 만들기**로 분류·메모·읽은 위치를 파일 하나로 저장합니다. 책 파일과 API 키는 들어 있지 않습니다.
- **백업에서 되돌리기**로 같은 파일을 불러옵니다. 되돌리기 직전의 기록은 데이터 폴더의 `library.before-restore.json`으로 남습니다.
- 다른 컴퓨터로 옮길 때도 이 백업 파일을 쓰면 됩니다. 책 파일의 경로가 다르면 폴더를 다시 연결해 주세요.
- 서재 기록 위치: 설치형은 `%AppData%\Theologia Library\data`, 압축형(윈도우)은 앱 폴더 안 `data`, 맥은 `~/Library/Application Support/Theologia Library/data`.

## 자주 묻는 질문
- **분류가 틀렸어요.** 책을 눌러 분류를 직접 고치세요. 직접 고친 분류는 자동 분류를 다시 돌려도 바뀌지 않습니다.
- **윈도우가 경고를 띄워요.** 서명 인증서를 쓰지 않은 앱이라 그렇습니다. "추가 정보 → 실행"을 누르세요.
- **스캔본 PDF 검색이 안 돼요.** 글자가 없는 이미지 PDF는 본문 검색이 되지 않습니다. 왼쪽 '본문 없음'에서 모아 볼 수 있습니다.
- **DRM이 걸린 EPUB은?** 열 수 없고 안내 문구만 보입니다.
- **문제를 알리고 싶어요.** [Issues](https://github.com/acts1615/theologia-library/issues)에 어떤 화면에서 무엇을 눌렀는지 적어 주세요.

## 안드로이드 앱 (시험판)
폰에 있는 책(PDF·EPUB) 폴더를 한 번 고르면 안의 책을 한꺼번에 불러와 분류하고, 목록과 PDF 읽기를 제공합니다. 분류 규칙은 PC 앱과 같은 코드를 씁니다.
- 받기: 릴리스 페이지의 `Theologia-Mobile.apk` (Actions → **android** → Run workflow 로 만듭니다)
- 설치: 폰에서 파일을 받아 열고, "출처를 알 수 없는 앱 설치"를 허용하면 됩니다. (서명되지 않은 시험판이라 Play 프로텍트가 경고할 수 있습니다.)
- 지금 되는 것: 폴더 불러오기, 분류별 보기, 검색, 분류·상태 고치기, PDF 읽기(이어 읽기, 쪽 이동, 확대)
- 아직 안 되는 것: EPUB 읽기, 서점 정보 채우기, PC와 동기화
- 소스는 `mobile/` 폴더에 있습니다.

## 업데이트
앱이 켜질 때 이 저장소의 최신 릴리스를 확인합니다. 새 버전이 있으면 왼쪽 아래에 알림이 뜨고,
"업데이트"를 누르면 내려받은 뒤 스스로 다시 시작합니다. 새 버전이 켜지지 않으면 이전 버전으로 자동으로 돌아갑니다.

## 개인정보와 키
- 카카오·국립중앙도서관 키는 앱 설정 창에 입력하며, 내 컴퓨터의 설정 파일에만 저장됩니다. 코드에는 들어 있지 않습니다.
- 서재 기록(읽은 위치, 책갈피, 메모)과 PDF 파일은 어디로도 전송되지 않습니다.
