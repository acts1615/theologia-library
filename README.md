# Theologia Library · 개인 신학 서재

흩어진 PDF·EPUB 신학 문헌을 작품(책) 단위로 묶어 관리하고, 앱 안에서 바로 읽는 개인 서재입니다.
Windows와 Mac에서 쓸 수 있습니다. 제작: 좋은군사

## 주요 기능
- 폴더를 연결하면 PDF·EPUB을 찾아 책 단위로 정리하고, 성경 66권·신학 분류를 자동으로 붙입니다.
- 앱 안 리더: 읽은 위치 자동 기록, 이어 읽기, 목차·책갈피, 책 안 검색(PDF·EPUB).
- 카카오(다음) 책 검색·국립중앙도서관으로 표지·저자·출판사·ISBN 자동 채우기(각자 API 키를 설정 창에 입력).
- 모든 서재 기록은 내 컴퓨터에만 저장됩니다.

## 업데이트
앱이 켜질 때 이 저장소의 최신 릴리스를 확인합니다. 새 버전이 있으면 왼쪽 아래에 알림이 뜨고,
"업데이트"를 누르면 내려받은 뒤 스스로 다시 시작합니다. 새 버전이 켜지지 않으면 이전 버전으로 자동으로 돌아갑니다.

## 개인정보와 키
- 카카오·국립중앙도서관 키는 앱 설정 창에 입력하며, 내 컴퓨터의 설정 파일에만 저장됩니다. 코드에는 들어 있지 않습니다.
- 서재 기록(읽은 위치, 책갈피, 메모)과 PDF 파일은 어디로도 전송되지 않습니다.
